# Striver's A2Z Sheet

Solutions to [Striver's A2Z DSA Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/) implemented in C++.

## Structure

Each folder corresponds to a step/topic from the sheet:

| Folder | Topic |
|--------|-------|
| 01 | Basics (Math, Recursion, Hashing) |
| 02 | Sorting |
| 03 | STL - Standard Template Library |
| 04 | Arrays |
| 05 | Binary Search |
| 06 | Strings |
| 07 | Linked List |
| 08 | Recursion & Backtracking |
| 09 | Bit Manipulation |
| 10 | Stack & Queue |
| 11 | Sliding Window & Two Pointer |
| 12 | Heaps |
| 13 | Greedy Algorithms |
| 14 | Binary Trees |
| 15 | Binary Search Trees |
| 16 | Graphs |
| 17 | Dynamic Programming |
| 18 | Tries |

## Language

All solutions are written in **C++**.
